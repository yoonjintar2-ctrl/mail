jinny mail 개인정보 처리방침

시행일 2026년 10월 29일

1. 어떤 정보를 다루나요

jinny mail(지니메일)은 사용자가 직접 로그인한 Google 계정의 Gmail 메일을 보여 주고, 메일을 보내는 크롬 확장 프로그램이에요. 이를 위해 Google이 허락한 범위 안에서 아래 권한을 써요.

  • Gmail 읽기(gmail.readonly): 메일 목록·본문·첨부를 화면에 보여 주고 검색하기 위해
  • Gmail 보내기(gmail.send): 사용자가 쓴 메일을 보내기 위해
  • Google 드라이브 앱 전용 공간(drive.appdata): 지니메일 편지함 구성·분류·서명 같은 설정을 사용자 본인의 드라이브 숨은 공간에 저장하기 위해
  • Google 드라이브 파일(drive.file): 사용자가 고른 첨부파일을 본인 드라이브에 저장할 때만

2. 정보는 어디로 가나요

메일과 설정은 사용자의 PC(브라우저 저장소)와 Google 서버 사이에서만 오가요. 지니메일은 별도 서버가 없고, 메일 내용·주소·첨부를 개발자나 다른 누구에게도 보내지 않아요. 광고, 분석, 판매, 제3자 제공을 하지 않아요.

3. 이 PC에 저장되는 것

빠르게 열고 검색하기 위해 메일 목록·본문을 이 PC의 브라우저 저장소에 저장해요. 사용자가 고른 경우에만 PC 폴더에 검색용 색인을 저장해요. 설정 → 일반의 '저장한 메일 비우기', 계정의 '로그아웃'으로 언제든 지울 수 있어요.

4. Google API 사용자 데이터 정책 준수

jinny mail이 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

5. 권한 철회

Google 계정 → 보안 → 타사 앱 액세스에서 jinny mail 권한을 언제든 해제할 수 있어요. 확장 프로그램을 삭제하면 이 PC에 저장된 정보도 함께 지워져요.
